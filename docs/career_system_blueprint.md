# Career System Blueprint: The Opportunity Map

## 1. Core Logic: The "Hybrid" Advantage
The system must prioritize roles that value the intersection of **Field Reality** (Site Execution) and **Commercial Control** (Contract Admin/SAP).

## 2. Priority Pathways
- **Path A: Engineering/Studies** (PSCAD/MATLAB/Design) - Focus on technical precision.
- **Path B: Commercial/Project Controls** (SAP/Contracts/Cost) - Focus on efficiency and leakage prevention.
- **Path C: Project Management/Coordination** (Execution/Vendors) - Focus on end-to-end ownership.

## 3. Data Sources
- **Direct**: Adani Careers, LinkedIn (Solar/Data Center/Power System filters).
- **Hidden Signals**: New project awards, MNRE internship/ecosystem posts, commissioning news.

## 4. Scoring Rubric
- **Relevance Score (0-1.0)**: 
    - +0.3 if role mentions "Contract/SAP/Billing".
    - +0.3 if role mentions "PSCAD/MATLAB/Power Systems".
    - +0.2 if location is "Ahmedabad" or "Gujarat".
    - +0.2 if sector is "Solar" or "Data Centers".
